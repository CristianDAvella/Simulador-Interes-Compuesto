      Pasos del cálculo

        Equivalencias de la tasa de origen

        ExpresiónValor

        Cuota fija (sistema francés)

        A = P · i / (1 − (1 + i)−n)

        Donde P es el monto del crédito, i es la tasa efectiva del periodo de pago (aquí, mensual) y n es el número de cuotas.

        Conversión entre expresiones de tasa

        Toda tasa se lleva primero a la tasa efectiva anual (EA), que funciona como pivote, y desde ahí se expresa en la forma que se necesite.

        • Nominal → periódica: tasa periódica = valor / m
        • Anticipada → vencida: i = d / (1 − d)
        • Periódica vencida → EA: EA = (1 + i)m − 1
        • EA → periódica vencida destino: i' = (1 + EA)1/m' − 1
        • Vencida → anticipada: d' = i' / (1 + i')
        • Periódica → nominal: resultado = d' × m'

        Recálculo tras un abono extraordinario

        • Reducir cuota: se mantienen las cuotas restantes (restantes) y se recalcula la cuota sobre el saldo después del abono: cuota = saldo · i / (1 − (1 + i)−restantes)
        • Reducir plazo: la cuota no cambia; se recalculan las cuotas restantes necesarias para pagar el saldo: restantes = ⌈ −ln(1 − saldo·i / cuota) / ln(1 + i) ⌉

        Convenciones adoptadas (A5, A6)

        • El abono se aplica después de la cuota ordinaria del mes y va 100 % a capital (supuesto A5).
        • Si se reduce el plazo, la última cuota puede quedar residual (menor a la vigente): es igual al saldo más el interés de ese mes (supuesto A6).
        • Máximo un abono por mes (decisión documentada en calculation-flow.md §3.2).
        • Precisión completa en los cálculos internos; el redondeo a pesos ocurre solo al mostrar en pantalla (§3.1).
